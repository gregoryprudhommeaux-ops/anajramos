# ANAJRAMOS

Site vitrine d’Ana Ramos-Prudhommeaux, consultante en recherche de cadres et développement du talent. Le design reprend la bio HTML (crème, marine, or, Playfair Display, Plus Jakarta Sans, cartes arrondies). Le contenu suit le brief *Website Strategy & Final Copy* d’octobre 2026.

Quatre langues, en pages séparées : anglais (EN, URLs principales), espagnol (`/es`), mandarin (`/cn`) et français (`/fr`). Le sélecteur affiche EN, ES, CN et FR.

## Lancer en local

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43123
```

Ouvrir [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Pages

- `/` accueil
- `/executive-search`
- `/search-firm-collaboration`
- `/talent-development`

- `/contact`

## Choix de publication

- Les noms de clients finaux du HTML d’origine (grilles de logos) ne sont pas affichés : le brief demande une validation avant toute publication.
- Les accréditations et le parcours daté viennent de la bio HTML fournie.
- Il n’y a pas de portrait. Le monogramme AR tient la place en attendant une photo validée.
- L’adresse `ana@anajramos.com` n’est pas affichée tant que la boîte n’est pas confirmée.
